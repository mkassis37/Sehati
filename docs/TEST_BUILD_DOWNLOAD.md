# تنزيل نسخة الاختبار (APK Artifact)

بعد نجاح GitHub Actions على الفرع `main`:

1. افتح تبويب **Actions** في مستودع Sehati.
2. اختر أحدث تشغيل ناجح لسير عمل **Android CI** على الفرع `main`.
3. من قسم **Artifacts** نزّل `sehati-debug-apk` لتثبيت التطبيق، أو `sehati-project-zip` للحصول على المشروع وAPK مع معلومات البناء.
4. احتفظ ببيانات التطبيق الحالية. لا تحذف النسخة القديمة قبل التأكد من توافق توقيع APK ونجاح تثبيت التحديث.

الحزمة التجريبية Debug وليست إصدار Play Store موقّعاً بمفتاح إنتاج. تنتهي صلاحية Artifacts بعد 14 يوماً.
